Tarea 3 — Crear schema de analytics interno

Crear:

supabase/analytics.sql

Debe ser idempotente y no destructivo.

Crear tabla:

product_events

Campos:
- id uuid primary key default gen_random_uuid()
- user_id uuid references profiles(id) on delete set null
- event_name text not null
- place_id uuid references places(id) on delete set null
- group_id uuid references groups(id) on delete set null
- app_event_id uuid references events(id) on delete set null
- topic_tag_id uuid references topic_tags(id) on delete set null
- metadata jsonb not null default '{}'
- session_id text
- platform text
- created_at timestamptz not null default now()

Índices:
- product_events(user_id, created_at desc)
- product_events(event_name, created_at desc)
- product_events(place_id, created_at desc)
- product_events(group_id, created_at desc)
- product_events(app_event_id, created_at desc)
- product_events(created_at desc)

Activar RLS.

Crear:

supabase/analytics-policies.sql

Policies:
- usuario autenticado puede insertar eventos propios con user_id = auth.uid().
- usuario no puede insertar eventos para otro user_id.
- usuario normal no puede leer todos los analytics.
- usuario puede leer sus propios eventos si hace falta.
- moderador/admin puede leer analytics agregados si se implementa.
- evitar exposición de eventos individuales de terceros.

No guardar coordenadas exactas.
No guardar secrets.
No guardar PII innecesaria.
