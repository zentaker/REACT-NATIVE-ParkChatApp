Tarea 5 — Validar RLS

Usar:

docs/RLS_CHECKLIST.md

Validar mínimo:

- Usuario autenticado puede leer places públicos.
- Usuario autenticado puede leer mensajes visibles.
- Usuario autenticado puede insertar place_messages con su propio user_id.
- Usuario NO puede insertar place_messages con user_id de otro usuario.
- Usuario puede leer perfiles básicos.
- Usuario solo puede actualizar su propio profile.
- Usuario puede crear reporte propio.
- Usuario puede crear bloqueo propio.
- Usuario no puede manipular reportes/bloqueos ajenos.
- Owner puede aprobar miembros pendientes donde aplique.
- Moderador puede acceder a moderation inbox donde aplique.

Si algo falla:
- documentar error exacto.
- proponer fix mínimo en supabase/policies.sql.
- no desactivar RLS globalmente.
- no usar service_role.
