Séptima tarea: preparar release workflow.

Revisar si existe:

.github/workflows/release.yml

Si no existe, crearlo.

Objetivo:
Cuando se suba un tag tipo v0.1.0, GitHub Actions crea un release con bundle fuente limpio.

Crear archivo:

.github/workflows/release.yml

Contenido sugerido:

name: Release

on:
  push:
    tags:
      - "v*"

permissions:
  contents: write

jobs:
  release:
    name: Create GitHub Release
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Create source bundle
        run: |
          mkdir -p dist
          zip -r dist/parkchat_source_bundle.zip . \
            -x ".git/*" \
            -x "dist/*" \
            -x "node_modules/*" \
            -x ".expo/*" \
            -x ".env" \
            -x ".env.*" \
            -x "web-build/*" \
            -x "android/*" \
            -x "ios/*" \
            -x "npm-debug.log*" \
            -x "yarn-debug.log*" \
            -x "yarn-error.log*"

      - name: Create release
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          gh release create "${GITHUB_REF_NAME}" \
            dist/parkchat_source_bundle.zip \
            --title "ParkChat ${GITHUB_REF_NAME}" \
            --generate-notes
