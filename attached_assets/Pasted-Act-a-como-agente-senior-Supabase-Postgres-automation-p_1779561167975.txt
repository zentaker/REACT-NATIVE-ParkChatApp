Tarea 1 — Preparar secrets esperados

Indícame que cree este secret en Replit:

Name:
SUPABASE_DB_PASSWORD

Value:
<database password de Supabase>

No continuar hasta que exista.

Tarea 2 — Construir SUPABASE_DB_URL en runtime

Crear script:

scripts/lib/supabase-db-url.mjs

Debe:
- leer SUPABASE_DB_PASSWORD desde process.env
- leer project ref desde EXPO_PUBLIC_SUPABASE_PROJECT_URL o EXPO_PUBLIC_SUPABASE_URL
- construir una connection string de pooler compatible con Supabase
- URL-encodear la password con encodeURIComponent
- nunca imprimir la URL completa
- exportar función getSupabaseDbUrl()

Si no puede inferir host/region del pooler automáticamente:
- pedir que agregue un secret adicional SUPABASE_DB_URL
- pero primero intentar con SUPABASE_DB_PASSWORD

Tarea 3 — Doctor seguro

Crear:

scripts/doctor-db-url.mjs

Debe validar:
- SUPABASE_DB_PASSWORD exists true/false
- password length solamente
- EXPO_PUBLIC_SUPABASE_PROJECT_URL o URL válida
- si puede construir DB URL
- host sin usuario/password si es seguro
- confirmar que NO existe EXPO_PUBLIC_SUPABASE_DB_PASSWORD
- confirmar que NO existe EXPO_PUBLIC_SUPABASE_DB_URL

No imprimir secretos.

Agregar script en package.json:

"supabase:doctor-db": "node scripts/doctor-db-url.mjs"

Tarea 4 — Si construcción automática no es viable

Si no puedes construir la connection string porque falta host/region/pooler:
- detenerte.
- pedirme crear SUPABASE_DB_URL como Secret.
- NO pedirme pegarlo en chat.
- explicar exactamente dónde pegarlo en Replit Secrets.

Tarea 5 — Crear ejecutor SQL

Instalar pg si falta:

npm install pg

Crear:

scripts/lib/db-admin.mjs
scripts/apply-supabase-sql.mjs

apply-supabase-sql debe aceptar:

node scripts/apply-supabase-sql.mjs --file supabase/policies.sql
node scripts/apply-supabase-sql.mjs --file supabase/triggers.sql
node scripts/apply-supabase-sql.mjs --file supabase/seed.sql
node scripts/apply-supabase-sql.mjs --all

En --all ejecutar:
1. supabase/triggers.sql
2. supabase/policies.sql
3. supabase/seed.sql

No ejecutar schema.sql por defecto porque las tablas ya existen.
No hacer DROP.
No borrar datos.

Agregar scripts:

"supabase:apply:policies": "node scripts/apply-supabase-sql.mjs --file supabase/policies.sql",
"supabase:apply:triggers": "node scripts/apply-supabase-sql.mjs --file supabase/triggers.sql",
"supabase:apply:seed": "node scripts/apply-supabase-sql.mjs --file supabase/seed.sql",
"supabase:apply:all": "node scripts/apply-supabase-sql.mjs --all"
