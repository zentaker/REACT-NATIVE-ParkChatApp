Tarea 6 — Strict geofenced posting configurable

Crear o actualizar:

services/geofence.ts

Funciones:
- canPostInPlaceChat({ userLocation, place, requireInsideRadius })
- getGeofenceStatus(userLocation, place)
- getGeofenceMessage(status)
- shouldRequireGeofencePosting()

Config:
- default: strict geofence OFF para no romper QA/web.
- permitir activar con variable:
  EXPO_PUBLIC_STRICT_GEOFENCE_POSTING=true

Reglas:
- si strict OFF: permitir post, mostrar badge/contexto.
- si strict ON y location granted:
  - permitir post solo dentro de radius_meters.
- si strict ON y location denied/unavailable:
  - bloquear post con mensaje claro.
- nunca enviar coordenada exacta a DB.
- no usar geofence para leer chats, solo para postear.
